# Changelog

## v3.0.1 — 2026-10-14

- gate 校验 FULL 专用模式与 profile 组合，严格区分整数 schema_version 与布尔/浮点值，错误枚举类型返回 BLOCKED。
- inspect 支持常见引用式 Markdown 和带标题/括号的内联目标，排除代码示例及注释；空 VERSION、非字符串或未支持的入口标量不再通过。
- 保留原 28 项测试，补充缺陷回归和合法对照；详细结果由项目修复报告记录。
- 配套 PowerShell 安装与恢复工具移到仓库 tools/；替换前写恢复计划，逐文件记录状态，保留安装后的用户改动。
- 完整目标应用行为、全量旧模型回归与长期效果保持未验证，不由检查器修复自动晋级生产。

## v3.0.0 — 2026-10-13

- 基于用户“进行系统性优化”的授权重构：短入口、九模式合同、LIGHT/FULL 与按需治理。

- 24 项固定结构改为适用性检查，移除空占位文件；详细资产、字体和视觉 QA 按任务加载。
- 新增标准库离线检查和证据门，区分记录完整、功能表现与目标部署。
- 旧 v2.4 在项目归档逐文件保存；能力去重、条件化与授权语义变更记录在本次能力映射。
- 主版本变化涉及治理合同和包目录；SEH 软件 v1.0.0 独立版本未更改。目标发布资格依赖实际证据。
